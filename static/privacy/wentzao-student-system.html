文藻學生系統｜隱私權政策

最後更新：2026 年 7 月 30 日

本擴充功能僅供文藻美語授權的內部教職員，在 LINE Official Account Manager 中處理學生服務使用，不對一般大眾開放。

一、單一用途

本擴充功能的用途是在 LINE Official Account Manager 內辨識目前的 LINE 聯絡人，將其綁定至學生與家長聯絡資料，並提供聯絡資訊、學費狀態、請假及補課紀錄等校務操作。

二、處理的資料

  • 學生與聯絡人資料：姓名、英文名、學號、班級、在校狀態、關係、電話、地址及 LINE 官方帳號識別碼。
  • 校務資料：學期、學費項目與繳費狀態、請假、缺席及補課紀錄。
  • 目前頁面資訊：目前開啟的 LINE Official Account Manager 聊天識別資訊，用來判斷要顯示哪一個家庭；不會將聊天訊息全文傳送至學生系統。

三、資料如何使用與傳輸

上述資料只用於提供本擴充功能的校務功能。擴充功能只會與 rainbowstudent.wentzao.com 的文藻學生系統 API 通訊；傳輸使用 HTTPS。資料不會出售、用於廣告、信用評分或與本擴充功能單一用途無關的分析。

四、資料保存與刪除

學生與校務資料保存於文藻學生系統及其既有校務資料來源，依學校內部資料管理規則維護。解除 LINE 綁定時會移除相對應的 LINE 官方帳號識別碼；其他學生資料不會因解除綁定而自動刪除。使用者可透過校內系統管理員申請更正或刪除。

五、權限與安全

擴充功能只在 chat.line.biz 頁面執行，並只允許連線至文藻學生系統 API。存取由學校網路、伺服器權限及 Chrome Web Store 私人發布名單共同限制。

六、第三方與揭露

本擴充功能不會將資料提供給資料仲介、廣告商或其他未授權第三方。LINE Official Account Manager 由 LINE Yahoo 提供，其服務仍受 LINE Yahoo 自身條款與隱私政策約束。

七、聯絡方式

如需查詢、更正或刪除資料，請透過文藻美語內部管理管道聯絡系統管理員。
